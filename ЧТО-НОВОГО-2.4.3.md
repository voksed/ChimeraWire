# CarneliaVPN 2.4.3 — что добавили и починили

Сводка изменений за рабочие сессии (июнь 2026). От переделки интерфейса до тучи функционала.

---

## Интерфейс

**Десктоп (Windows)**
- Системный трей: иконка, меню (Открыть / Подключить / Выход), закрытие окна сворачивает в трей — VPN продолжает работать
- Иконки везде заменены на лого Carnelia: заголовок окна, сайдбар, **иконка exe-файла** (была заглушка — андроид-робот), карточки серверов, кнопка «Добавить», кнопка питания (MDL2-глифы вместо случайных символов)
- Установщик Inno Setup (`installer/CarneliaVPN.iss`) — нормальный мастер с лого, бандлит все Qt-DLL правильно

**Android**
- Секретная voks-тема + пасхалка
- 7 инструментов в Tools Hub: Fingerprint, DNS Audit, Route Tracer, Traffic Graph, TLS Inspector, Packet Inspector, Leak Test

---

## Функционал

### GPS-спуфинг — карта починена и прокачана
- **Тайлы карты теперь грузятся** (был баг: кэш osmdroid писался в недоступную папку на Android 11)
- **Зум и панорамирование работают** (скролл страницы больше не перехватывает жесты) + кнопки зума +/−
- **Поиск места по названию** — город, адрес, любая точка (геокодер OpenStreetMap, без Google)
- Синхронизация состояния кнопки Старт/Стоп

### Debug-панель (Android)
- Открывается **долгим нажатием на кнопку подключения**
- Фильтры логов по уровням, поиск по логам (grep)
- Копирование / шаринг / сохранение логов в Downloads
- Проверка внешнего IP через VPN, тип сети, последний сервер, ошибка, аптайм, трафик TX/RX

### Импорт конфигов (Android)
- Из Телеграма и файловых менеджеров: JSON-файлы, ACTION_VIEW / ACTION_SEND
- Несколько ключей разом (построчный список)
- Deep links TON Connect больше не ломают файловый импорт

### WireGuard / AmneziaWG (Android)
- Редактор настроек для каждого сервера: MTU, Jc/Jmin/Jmax, S1/S2, H1–H4
- Спец-пакеты I1–I5 (AmneziaWG 1.5) — парсятся и сохраняются

## Проверено вживую

- **Android**: установлен на SM-S948B, импорты/карта/поиск/AWG-настройки протестированы
- **Десктоп**: полный прогон с нуля — установка из инсталлера → запуск от админа → **TUN-режим** (адаптер «CarneliaVPN» Up, весь трафик через туннель, реальный трафик 4.5 MB/s) → чистое отключение
